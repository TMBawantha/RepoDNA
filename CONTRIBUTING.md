# Contributing to RepoDNA

Thank you for your interest in contributing to RepoDNA! Contributions of all experience levels are welcome.

## Getting Started

Use Node.js 22.12 or later and pnpm 12.

1. Fork the repository.
2. Clone your fork locally.
3. Install dependencies with `pnpm install`.
4. Create a new branch for your changes.
5. Run `pnpm dev` to start the development server and test your changes.
6. Run `pnpm build` to type-check and build the project.
7. Submit a pull request.

Commit any changes to `pnpm-lock.yaml` when you update dependencies.

## Development Guidelines

- Use TypeScript and follow the feature-based structure in `src/modules/`.
- Keep changes simple, readable, and focused.
- Avoid unnecessary dependencies.
- Write clear commit messages.
- Update documentation when necessary.

## Issues

Check existing GitHub issues before opening a new one. To report a bug, include steps to reproduce it and describe what you expected and what happened. To suggest an improvement, describe the problem it would solve.

## Pull Requests

Explain what changed and why, reference related issues, and describe how you verified the change. Ensure the project builds successfully.
