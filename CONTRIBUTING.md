# Contributing to RepoDNA

## Report bugs or suggest improvements

Search the existing GitHub issues before opening a new one. For a bug, include the steps to reproduce it, what you expected, what happened, and any relevant environment details. Use a small example and remove secrets or private code before sharing. For an improvement, describe the problem it would solve and give an example of how you would use it.

## Submit a change

1. Fork the repository and create a branch for your change.
2. Keep the change focused and update any affected documentation.
3. Run the checks relevant to your change and note what you verified.
4. Open a pull request against the upstream repository. Describe the change, link any related issue, and include verification steps or screenshots where applicable.

Follow the [code of conduct](CODE_OF_CONDUCT.md) when participating. Contributions are licensed under the [Apache License 2.0](LICENSE).
